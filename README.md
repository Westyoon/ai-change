## 8. 반응형 웹 지원

본 게임은 PC와 모바일에서 모두 플레이할 수 있도록 반응형으로 개발합니다.

### 지원 화면

| 환경    |        기준 | 대응 방식                |
| ----- | --------: | -------------------- |
| 모바일   |  320px 이상 | 터치 버튼, 세로 또는 가로 배치   |
| 태블릿   |  768px 이상 | 게임 화면과 UI 크기 조정      |
| PC    | 1024px 이상 | 키보드·마우스 조작, 최대 크기 제한 |
| 대형 화면 | 1440px 이상 | 게임 영역 과도한 확대 방지      |

### 화면 대응 원칙

* 화면 너비에 따라 게임 영역과 UI 크기를 조정합니다.
* 화면 비율이 달라도 주요 UI가 잘리지 않도록 합니다.
* 작은 화면에서 버튼이 겹치지 않도록 합니다.
* 게임 화면은 필요에 따라 최대 너비와 최대 높이를 설정합니다.
* 모바일 브라우저의 주소창 높이 변화를 고려합니다.
* 가로형 게임이라면 세로 화면에서 기기 회전 안내를 표시합니다.
* 화면 회전 후 게임 상태와 점수를 유지합니다.
* 모바일에서 불필요한 스크롤과 당겨서 새로고침을 방지합니다.
