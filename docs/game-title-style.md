# 게임 이름 표시 통일

2026-10-27 플레이 화면의 게임 이름을 `game-title` 공통 스타일로 통일했다. 사전 미니게임 5개와 사후 전투 5개는 게임 목록의 공식 `title`을 상단에 표시한다. Galmuri11, 보통 굵기 400, 크기 `.9rem`~`1.15rem`, 아이보리 글자와 보라색 배경, 같은 테두리·여백·행간을 사용한다. 제목 앞에 개별적으로 붙이던 장식 이모지는 제거했다.

AI·CS 내부 시작창과 X알의 개별 시험 제목도 같은 스타일을 사용한다. CSE·컨트롤 보스의 플레이 보드 내부 제목은 호스트 상단 제목과 중복되므로 숨기고 타이머·단계 표시는 기존 쪽에 유지한다. 별도 게임 방법 화면의 기존 구성과 결과 제목·문제 지문의 계층은 유지한다.

로컬 브라우저에서 사전 5개·사후 5개 게임을 실제 호스트에 마운트해 1280×844, 390×844, 320×844, 844×390에서 제목의 문구·글꼴·크기·굵기·색상·배경·줄바꿈과 화면 범위를 확인했다. 검증에는 모의 진행 기록과 게스트 테스트 세션을 사용했으며 계정 기록을 수정하지 않았다.
