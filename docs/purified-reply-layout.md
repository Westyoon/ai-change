# 말을 부순 뒤의 문장 정렬

2026-10-27 정화된 긍정 문장을 공격 문장의 좁은 사각형에 넣던 방식을 수정했다. 문장 전체를 하나의 텍스트 요소로 표시하고, 전투판 안쪽 폭을 사용한다. 단어를 중간에 끊지 않으며 긴 문장은 균형 있게 줄바꿈한다. 문장 높이는 내용에 따라 늘어나고, 화면 위·아래 끝에서도 잘리지 않게 중심 위치를 제한한다.

반응 문장은 공격 글자·탄환과 다른 레이어의 짙은 녹색 상자에 표시한다. 동시에 여러 문장을 정화하면 세 문장까지 서로 떨어지도록 배치한다. 전투판 폭이 특히 좁은 가로 휴대폰에서는 최신 문장 하나를 중앙에 표시해 겹침을 막는다. 기존 공격·충돌 사각형, 정화 점수, 문장이 남는 시간은 변경하지 않는다. 재사용한 문장 요소는 원래 문장이 사라질 때 제거하며, 동작 줄이기 설정에서는 등장 애니메이션을 끈다.

원고의 긍정 문장 55개 전체를 1366×768, 1280×720, 1024×768, 390×844, 320×844, 844×390에서 표시해 전체 문장·단어 유지·영역 초과를 검사한다. 화면 가장자리와 가운데에 세 문장을 동시에 배치해 겹침도 확인한다. 이아이의 별도 대사창을 함께 표시해 분리를 확인한다.
