# 온실 낮은 테라스 v4

단상은 이전 320×208에서 448×256으로 넓혔다(같은 공통 배율 적용 전 기준, 면적 약 1.72배). 캐노피와 기둥도 함께 확장했다. 높은 전면 벽처럼 보이던 석재 이미지를 낮은 앞면 8px의 단상과 얕은 3단 계단으로 교체했다. 계단 윗단은 단상 바닥면 끝에 붙인다.

단상 안에는 흰색 철제 테이블 2개와 의자 8개를 배치하고 기존 벤치는 제거했다. 가운데 이동 통로를 남겨 두고 각 가구의 충돌을 연결한다. 지붕 아래에서 캐노피가 옅어지는 기능을 유지한다.

`assets/maps/ecc/terrace-low.svg`, `terrace-steps-low.svg`, `white-cafe-table.svg`, `white-chair*.svg`는 편집 가능한 코드 기반 픽셀 에셋이다. 소스 좌표·배치는 공통 스킨과 실내 배치 모듈에 연결한다. 원본 생성 아틀라스는 수정하지 않았다. 운영 배포 없이 로컬 실험 브랜치에 적용한다.
