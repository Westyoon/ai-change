# 공대 산책 보상

야외 사후맵 우측 상단 (1600, 88)에 접근하면 “공대로 올라갈까요?” 확인창이 열린다. 수락하면 체력 스탯 +1 (저장된 최대 HP +100)을 지급한다. 사용/남은 횟수는 화면에 표시하지 않으며, 세 번을 모두 받고 다시 시도하면 “... 더 이상 힘들어서 올라갈 수가 없다.”를 표시한다. 계정당 평생 최대 3회이며 취소는 횟수를 쓰지 않는다. 로그인은 기존 계정 API에서 확인한다.

서버는 UUID 요청 키를 받아 산책 보상 원장에 기록한다. 계정별 1~3회 번호와 요청 키에 각각 유일 제약을 걸고, 원장 INSERT와 HP 증가 트리거가 같은 SQLite 문장의 트랜잭션에서 실행된다. 재시도·중복·동시 요청도 3회를 초과할 수 없다. 같은 확인창의 재시도는 같은 키를 쓰며 새 산책은 새 키를 사용한다.

`0016_campus_walk_three_claims.sql`은 이전 `campus_walk_claims` 기록을 첫 번째 횟수로 가져오며 과거 HP를 중복 지급하지 않는다. 배포 교체 중 이전 Worker가 기록하는 산책도 원장에 반영한다. 기존 보상 값은 그대로 보존한다. 신규 원장도 이전 기록 테이블을 채우므로 이전 Worker로 복귀하더라도 산책 이력이 사라지지 않는다.

검증: 실제 Worker와 SQLite를 연결한 계약 검사에서 3회 제한·동시 요청·재시도·계정 격리·인증/Origin 검사·기존 마이그레이션 전체 적용·과거 보상 보존을 확인한다. 브라우저에서는 이전 좌측 상단 미발동, 우측 상단 자동 확인창, 취소, 1~3회 성공 문구, 4회 한도 안내, 사전맵 미노출을 확인한다.
