# 게임 공통 픽셀 스타일

사전게임의 장난감 보드 표현을 사후게임까지 연결한다. 별도 이미지 생성 없이 CSS와 Canvas에서 그리는 요소를 통일한다.

- 기본 팔레트: 분홍 `#d82f76`, 마젠타 `#e333bb`, 보라 `#363367`, 하늘 `#2ab5e4`. 노랑은 강조색으로 사용한다.
- 재질: 자주색 외곽선, 아이보리 하이라이트, 아래쪽에 번짐 없는 단단한 그림자. 패널과 버튼은 작은 각진 모서리를 사용한다.
- 공과 작은 오브젝트는 계단형 윤곽을 사용한다. Canvas 공통 함수는 `js/minigames/shared/pixel-drawing.js`에 둔다.
- `css/game-pixel-theme.css`를 마지막으로 불러온다. `#app` 안의 실제 게임 UI에만 적용한다.
- 기존 인데사 장난감 보드와 연결되도록 숫자야구 키패드/슬롯, 컴공 작업대/재료 버튼, AI 분류 패널/공, 보안 게임 정화 게이지/위협, X알 카드/버튼, 보스 체력바/오브젝트/조작부에 적용한다.
- 배경·수호알·캐릭터 이미지는 기존 리소스를 사용한다. 화면 비율, 위치, 조작, 충돌 판정, 제한 시간과 보상 수치는 수정하지 않는다.
- 재료 종류, 정답·오답, 뚜껑 열림·닫힘, 위험 바닥·구멍·완료 칸, 파티원 사망을 나타내는 색과 상태는 구분한다. 충격파의 원형 범위와 타이밍 판정 링도 유지한다.
- 버튼의 hover는 실제 마우스가 있는 장치의 활성 버튼에만 적용한다. 키보드 포커스는 하늘색 외곽선으로 표시한다.

확인할 화면: 노트북 가로 화면 / 모바일 세로 화면, 각 게임의 시작·실행·결과, 버튼 비활성, CSE 재료별 색, 보스 위험·경직·사망 상태.

## 수호알 분류와 기록 목록

- 숫자야구 기록은 `align-content: start`와 `grid-auto-rows: max-content`로 영역 높이에 관계없이 위에서부터 순서대로 붙여 표시한다.
- 인데부 분류는 기존 인지/데사 두 종류를 유지한다. 인지에는 AI 성장의 수호알, 데사에는 DS 통찰의 수호알을 표시하고 받는 상자에도 같은 이미지와 색을 사용한다.
- 수호알 회전은 실제 발판 이동 거리/반지름으로 계산한다. 좌우 이동을 따라 회전 방향이 바뀌고, 공중에서도 직전 각속도를 이어간다. 프레임 시간으로 계산하므로 일시정지 중에는 회전하지 않는다. 충돌 판정은 기존 반지름을 사용한다.
- AI 정보 선별 상자는 `sorting-bin-pixel.png`로 교체했다. 원본을 보관하고 투명 여백만 소스 좌표에서 제외한다. 생성 정보는 `asset-sources.md`와 `sorting-bin-pixel-prompt.md`를 참고한다.

## 수호알 인벤토리

- 열린 팝업은 `document.body`의 별도 레이어로 옮겨 맵의 잘림과 애니메이션 영향을 받지 않도록 한다. 닫으면 원래 위치로 복귀하며 화면을 떠나면 레이어도 제거한다.
- 제목과 수집 현황은 상단, `우리의 기억`은 하단 고정 행에 둔다. 가운데 수호알 목록만 스크롤하며 모바일에서도 한 열로 설명을 함께 표시한다.
- 팝업 높이는 화면의 동적 높이와 안전 영역을 기준으로 제한한다. 팝업이 열려 있는 동안 원래 수호알 버튼은 자리를 유지한 채 숨겨 겹침을 방지한다.
