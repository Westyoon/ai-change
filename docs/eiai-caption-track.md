# 전투 밖 이아이 대사창

2026-10-27 전투판 안에서 공격 글자 뒤로 나오던 이아이 자막을 전용 대사창으로 옮겼다. 노트북에서는 왼쪽의 빈 공간을 사용해 기존에 확대한 전투판 크기를 유지한다. 세로 휴대폰에서는 하단의 고정 안내 영역을 사용하고, 대사 동안 알 표시를 숨긴 뒤 부드럽게 복구한다. 조이스틱은 해당 영역 위로 옮겨 문장을 가리지 않는다. 가로 휴대폰에서는 대사·알 표시가 오른쪽 영역을 번갈아 사용하고 조이스틱은 왼쪽에 둔다.

X알 초상, 화자 이름, 보통 굵기의 문장과 짧은 등장·퇴장 전환으로 발언을 구분한다. 문장을 한 번에 온전히 표시하며 6.5초 동안 유지한다. 기존의 무작위 대사 10개와 8~12초 등장 주기는 유지하고, 일시정지·수호알 응원 중에는 대사 시간이 흐르지 않는다. 수호알 장면이 열리면 이아이 대사창을 비우고, 재시작·퇴장 시 기존 전투 생명주기와 함께 정리한다. 동작 줄이기 설정에서는 전환을 끈다.

읽기 검증은 실제 대사 10개 전체를 1366×768, 1280×720, 1024×768, 390×844, 320×844, 844×390에서 표시해 수행했다. 공격판과의 분리, 문장 전체의 영역 내 표시, 조이스틱과의 비겹침, 대사 종료 후 알 표시 복구를 확인한다. 전투·충돌·보상 로직은 변경하지 않는다.
