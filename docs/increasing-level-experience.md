# 증가하는 레벨 경험치

2026-10-05 변경. 다음 레벨 n으로 오르는 데 필요한 경험치는 `(n - 1) × 100 EXP`이다. 1→2는 100, 2→3은 200, 3→4는 300 EXP이며 각 레벨업마다 스탯 포인트 1개를 지급한다. 누적 기준은 0 / 100 / 300 / 600 / 1000 EXP이다. 유효한 사후게임 클리어마다 서버가 100~200 EXP를 10 단위로 무작위 지급한다. 각 파티원의 보상은 개별로 뽑으며 재시도 멱등 처리는 유지한다.

계정 화면은 누적 총 경험치 대신 현재 레벨에서 모은 경험치 / 해당 레벨업 비용을 표시한다. 예를 들어 누적 160 EXP, Lv. 2는 `60 / 200`이다. 서버·Durable Object의 보상 계산은 공통 progression 모듈을 사용한다.

마이그레이션 0014는 기존 레벨, 배분된 스탯과 미사용 포인트를 보존한다. 기존 레벨의 시작 경험치만 새 누적 기준으로 올리고 현재 레벨에서 모은 경험치를 유지한다. Lv. 15, 기존 누적 1440은 새 누적 10540으로 변환되어 Lv. 15와 진행 40 / 1500을 유지한다. 과거 문서의 고정 100 EXP 또는 클리어당 포인트 1개 설명은 이 정책으로 대체된다.
