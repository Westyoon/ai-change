# 캠퍼스 내부맵 구현

2026-10-24 사용자 요청에 따라 야외와 ECC·학생문화관·온실 내부를 함께 운영 배포했다. 최신 코드 기준은 `feature/ecc-tile-map`의 `b06daa5`이며 운영 Worker 버전은 `a4813b08-146c-4ff6-9d53-c493615ab61c`이다. 운영 주소는 https://ai-change.ai-change-backend.workers.dev 이다. 직전 내부맵 배포 버전은 `db478276-76b3-43e4-873e-61c9929a14ad`, 초기 야외 배포 버전은 `5a3fb871-5b6b-4703-a21e-88040e618b5e`로 기록한다.

맵 상단의 공간 이름과 사전·사후 전환/캠퍼스로/돌아가기 툴바를 제거했다. 이동은 기존 건물 출입구의 상호작용으로 연결하며, 확보한 세로 공간을 맵 뷰포트가 사용한다. 캐릭터 추적 카메라와 이동·충돌은 유지한다.

전체 검사 통과: 테스트 519개, 소스 HTTP 검사 80개, 빌드 HTTP 검사 93개, 백엔드 TypeScript 검사. 운영 D1에는 추가 migration이 없었다. 배포에는 기존 계정 API·D1·Durable Object binding을 가진 통합 Worker를 사용했다.

배포 후 주요 JS·CSS·설정·새 에셋 7개를 운영 응답과 로컬 dist의 SHA-256으로 대조했고 API health는 `ok`였다. 실제 운영 앱에서 PC 1280px·모바일 390px 모두 Story 메뉴 → 캠퍼스 → 세 건물 입장 → 출입구로 캠퍼스 복귀를 확인했다. 모바일 조이스틱과 툴바 제거도 확인했으며 브라우저 오류는 없었다. `campusMap` 쿼리는 기존대로 localhost 전용 미리보기다.

## 아트와 이동

사전게임은 ECC 내부에서 시작한다. 야외의 학과 표시는 제거하고, ECC의 좌우 복도와 중앙 쉼터에 학생 실루엣 5명을 분산 배치했다. 학생은 클릭·터치로 대화를 열며, 가까이에서는 E키·스페이스바로도 말을 걸 수 있다. 첫 만남·재방문·클리어 후 이야기를 기존 학과별 진행 기록으로 구분한다. 대화와 게임에서 돌아오면 ECC에서 저장한 위치를 복원한다. 사후게임은 야외에서 시작하며 학생 실루엣을 표시하지 않는다.

운영 배포 후에도 1280px/390px에서 다섯 학생의 클릭 대화, 재방문/클리어 후 대화 분기, 사전·사후 세 건물의 스페이스바 입장을 확인했다. 실제 Story 메뉴에서 ECC 시작 → 학생 대화 → 게임 안내 → 저장한 ECC 위치로 복귀하는 흐름도 PC와 터치 모바일에서 통과했다.

맵 상호작용에 스페이스바를 추가했다. 공용 InputManager의 CONFIRM 바인딩을 전역 변경하지 않고, 캠퍼스 장면에서 Space의 최초 입력만 받는다. E키와 화면 버튼도 유지한다. 학생 실루엣은 기존 캐릭터 스프라이트를 같은 크기로 렌더링하고 단색 필터를 적용한다.

최신 아트 수정은 [유리벽·화강석 바닥·온실 화단 정돈](glass-garden-refinement.md)이며 이번 운영 배포에 포함했다. 해당 문서의 로컬 전용 표기는 제작 당시 상태다.

학생문화관 휴식 소파는 반복 조각을 제거하고 [단일 ㄱ자 에셋](student-continuous-sofa.md) 1개로 교체했다. 가운데 빈 부분은 통과 가능한 다각형 충돌을 사용한다.

온실 단상 최신 보완은 [낮은 테라스 v4](conservatory-terrace-v4.md)다. 면적을 약 1.72배로 넓히고 단 높이·계단을 낮췄으며 흰색 철제 테이블 2개와 의자 8개를 배치했다.

학생문화관 최신 배치는 [광장 배치 v4](student-center-v4.md)이다. 회색 타일, 북쪽 벽 경비실, 광장 쪽 서쪽 출입문 2개와 회색 소파, 중앙 네모 테이블을 적용했다. 엘리베이터와 벤치는 제거했다.

2026-10-24 온실 건축 보완: 무거운 팔각 돔과 목재 계단을 흰색 철제 캐노피·가는 기둥·밝은 석재 단상·7단 계단으로 교체했다. 계단 윗단은 단상 바닥면에 연결하고, 온실 상단에 유리 천장 프레임을 배치했다. 플레이어가 지붕 아래에 들어가면 캐노피를 옅게 표시한다. 제작 및 검증 정보는 [온실 v3](conservatory-v3.md)에 있다.

## 로컬 확인

`$env:PORT='5080'; node scripts/serve.mjs`

- ECC: http://127.0.0.1:5080/?campusMap=ecc_interior
- 학생문화관: http://127.0.0.1:5080/?campusMap=student_center_interior
- 온실: http://127.0.0.1:5080/?campusMap=greenhouse_interior

이 바로가기 파라미터는 localhost에서만 동작한다.

검증: 전체 테스트 516개, 릴리스 HTTP 검사, 서버 타입 검사 통과. 발밑 충돌 박스로 교실·공부방·정자와 모든 출입구의 연결성을 검사했고, 실제 브라우저에서 세 맵의 입장·이동·퇴장과 모바일 조이스틱을 확인했다.
