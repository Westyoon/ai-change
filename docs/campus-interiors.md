# 캠퍼스 내부맵 로컬 구현

야외 배포 기준 커밋은 `a98acb6`이고, 내부맵은 `feature/campus-interiors`에서만 작업한다. 야외 운영 배포 버전은 `5a3fb871-5b6b-4703-a21e-88040e618b5e`이다. 이 브랜치에서는 운영 배포를 실행하지 않았다.

## 아트와 이동

- ECC: 참고한 U자형 구조, 교실 6곳과 복도. 중앙 벤치를 제거하고 녹색 쿠션이 놓인 목재 휴게계단으로 변경했다. 교실 문은 흰색 프레임의 유리문이며 복도 쪽 문도 연결했다.
- 학생문화관: 초록 소파 두 구역, 중앙 로비, 오른쪽 공부방. 공부방 아래 출입구로 드나든다.
- 온실: 유리벽, 중앙 분수, 식재 공간, 상단 정자와 계단. 원형 분수는 다각형 충돌 영역을 사용한다.

세 실내맵 모두 [타일·개별 오브젝트 방식](ecc-tile-map.md)으로 재구성했다. 기존 전체 PNG는 현재 렌더링에 사용하지 않는다. 각 월드는 3072×2048이고, 공통 캠퍼스 아트를 사용한다. 맵은 카메라를 따라 일부만 표시되며 플레이어 좌표는 화면 크기와 독립적이다. 현재 작업 브랜치는 `feature/ecc-tile-map`이다.

야외의 ECC 아래쪽, 학생문화관 앞, 온실 앞에서 E키 또는 입장 버튼을 사용한다. 실내 출입구 또는 상단 `캠퍼스로` 버튼으로 돌아온다. 사전·사후 모드를 유지하며 맵마다 위치를 저장한다. 온라인 좌표는 맵별 공개 구역 ID로 분리했다. 실내 동접 검증은 이번 확인 범위에 포함하지 않았다.

## 로컬 확인

`$env:PORT='5080'; node scripts/serve.mjs`

- ECC: http://127.0.0.1:5080/?campusMap=ecc_interior
- 학생문화관: http://127.0.0.1:5080/?campusMap=student_center_interior
- 온실: http://127.0.0.1:5080/?campusMap=greenhouse_interior

이 바로가기 파라미터는 localhost에서만 동작한다.

검증: 전체 테스트 516개, 릴리스 HTTP 검사, 서버 타입 검사 통과. 발밑 충돌 박스로 교실·공부방·정자와 모든 출입구의 연결성을 검사했고, 실제 브라우저에서 세 맵의 입장·이동·퇴장과 모바일 조이스틱을 확인했다.
