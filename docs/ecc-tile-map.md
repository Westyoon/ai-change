# ECC 타일·개별 오브젝트 구현

이 버전의 ECC는 전체 맵 이미지를 사용하지 않는다. 기존 PNG는 비교용으로만 남아 있고, `background`는 `null`이다. 초기 3072×2048 배치에서 가로·세로를 15% 줄여 현재 월드는 2611×1741이다. 배치·충돌·문 위치·입장·퇴장 좌표를 함께 조정했고 캐릭터 크기와 카메라 배율은 유지한다.

## 구성

- `assets/maps/interior/`: 기존 캠퍼스 그림을 참고한 공통 스프라이트 아틀라스. 벽·유리·문, 가구, 식물을 각각 잘라 독립 배치한다. 보도블록과 벤치는 기존 야외 에셋을 그대로 재사용한다. `assets/maps/ecc/`의 SVG는 대체 리소스로 유지한다.
- `js/map/ecc-layout.js`: 바닥 영역 15개와 독립 오브젝트 332개의 배치. 교실 6곳, 복도, 목재 쿠션 계단을 구성한다. 배치마다 충돌 박스를 함께 정의한다.
- `js/map/tile-map-renderer.js`: 바닥 타일 반복, 개별 이미지 배치, 발밑 좌표에 따른 앞뒤 순서, 문 12개의 자동 열림·닫힘을 처리한다.
- `CampusMapManager`: 같은 배치 데이터에서 이동 마스크를 만든다. 오브젝트를 옮기면 충돌도 같이 옮겨진다.

원본 에셋 미리보기는 로컬의 `/assets/maps/ecc/`에 있다. 맵 확인 주소는 `http://127.0.0.1:5080/?campusMap=ecc_interior`이다. 마우스·터치 화면 크기와 월드 좌표는 독립적이다.

## 검증

중앙 쉼터는 실제 ECC 참고 사진을 반영해 넓은 목재 단 3개와 초록·파랑 긴 쿠션 좌석, 파란 큐브 좌석을 엇갈려 배치했다. 양옆 이동 계단을 유지하고 좌석마다 충돌을 연결했다. 해당 개별 에셋은 `assets/maps/ecc/cushion-green.svg`, `cushion-blue.svg`, `ottoman-blue.svg`, `lounge-riser.svg`, `lounge-stairs.svg`이다.

전체 테스트 517개, 릴리스 검사와 서버 타입 검사 통과. 모든 교실·출입구의 연결성, 벽·가구 충돌, 전체 배경 이미지가 없는 DOM 구조, 가까이서 열리고 멀어지면 닫히는 문을 검증했다. 세 내부맵의 입장·이동·퇴장과 모바일 화면도 확인했다.

이 변경은 `feature/ecc-tile-map`에서 로컬로 진행하며 운영에 배포하지 않았다. 학생문화관·온실에도 같은 공통 아트와 개별 배치 방식을 적용했다. 최신 검증은 전체 테스트 518개, 릴리스 HTTP 검사 93개, 서버 타입 검사 통과. 아트 제작 정보는 [공통 아트 기록](interior-campus-art.md)을 참고한다.
