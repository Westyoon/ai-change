# 이아이 보스전의 수호알 응원

2026-10-27 각 학과의 수호알이 깨어날 때 전투를 멈추고 짧은 응원 장면을 표시한다. 기존 알 원본과 학과색을 사용해 등장 연출, 학과명, 사전 이야기의 벗을 떠올리는 문장, 각 라운드의 `recoveryMessage`를 온전히 보여준다. 마지막 알에서는 다섯 알과 함께 이아이에게 응원을 전하고 다시 일어서는 흐름을 연결한다. 시작 대화와 조작 안내에도 수호알의 역할을 설명한다.

읽는 동안 이동·공격·피격·전투 타이머와 이아이의 다른 자막은 진행하지 않는다. 클릭·터치·Enter·Space·E로 이어가며, 이동 입력을 비워 눌러 둔 방향키가 재개 직후 남지 않게 한다. Esc/P와 상단 버튼의 일시정지는 별도로 유지한다. 일시정지 중에는 응원 버튼으로 전투를 재개할 수 없고, 재시작·퇴장 시 읽던 장면을 제거한다. 알 지급·생명·충돌·라운드·최종 결과와 보상 판정은 기존 전투 로직을 사용한다.

응원은 화면 대사와 기존 음량 설정을 따르는 합성 획득 효과음으로 표시한다. 응원 중에는 잔잔한 곡으로 바뀌며, 실제 녹음 음성은 포함하지 않는다. 동작 줄이기 설정에서는 알 등장 애니메이션을 끈다.

검증: 실제 전투 어댑터에서 다섯 장면을 차례로 확인하고, 읽는 동안 스냅샷 불변·일시정지·재개·읽던 장면에서 재시작·최종 완료 1회·정리를 확인한다. 브라우저에서는 PC 1280px, 터치 390px, 320px, 가로 844×390에서 내용과 버튼의 가로 넘침, 클릭·터치·Space 및 동작 줄이기를 검사한다. 진행 기록은 검사용 모의 상태이며 실제 계정에는 쓰지 않는다.
