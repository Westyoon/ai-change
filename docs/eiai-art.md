# 이아이 원본 이미지 적용

2026-10-27 사용자 제공 `C:/Users/yoons/Downloads/이아이.png`를 [eiai-pixel.png](../assets/images/eiai-pixel.png)로 그대로 복사했다. 256×256 RGBA, 2,279바이트이며 배경은 투명하다. 재생성·리사이즈·색상 변경 없이 원본 바이트를 보존한다.

`festival-art.js`의 `EIAI_IMAGE_SRC`를 공통 경로로 사용한다. 대강당 앞 이아이 상호작용, 이아이가 말하는 대화 컷, 최종 전투와 마지막 수호알 장면, 회복 엔딩과 축제 메뉴에 같은 이미지를 표시한다. 엔딩에서는 이미 동행 이미지가 있으므로 대화 컷을 중복해서 표시하지 않는다. 픽셀 렌더링과 정사각형 비율을 유지한다.

대화 내용·진행 판정·전투·보상·캐릭터 이동은 유지하며, 대강당의 기존 이아이 진입점은 이미지 버튼과 근접 상호작용으로 연결한다.
