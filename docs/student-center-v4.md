# 학생문화관 광장 배치 v4

회색 석재 바닥, 북쪽 벽에 붙인 경비실, 광장을 향하는 공부 라운지 서쪽 출입문 2개로 수정했다. 엘리베이터와 벤치는 제거했다. 라운지 남쪽 벽은 막혀 있고, 서쪽 문 앞 광장에는 기존 낮은 소파 형태를 유지한 회색 소파 두 개를 배치했다.

공부 라운지 중앙에 각진 네모 테이블 2개와 의자 8개를 배치했다. 오른쪽 벽의 책상 8석과 그 앞 의자는 유지한다. 책상은 원본 종횡비를 유지하고 오른쪽에 정렬해 벽에 붙이므로 책·조명이 가로로 늘어나지 않는다. 출입구·중앙 테이블 주변과 오른쪽 책상 앞을 이동할 수 있다.

`assets/maps/ecc/student-grey.svg`와 `square-table.svg`는 편집 가능한 코드 기반 픽셀 타일·가구다. 바닥은 16 월드 픽셀의 정사각형 석재 패턴과 낮은 대비의 줄눈을 사용한다. 회색 소파는 기존 아틀라스 원본을 바꾸지 않고 렌더링 색상 행렬로 중립 회색을 표시한다. 전체 맵 이미지를 사용하지 않는다. 관련 설정은 `data/maps/interior-skin.json`, 배치는 `js/map/interior-layouts.js`다.

운영 배포 없이 실험 브랜치와 로컬 서버에서 확인한다.
