# 주요 기능별 구현 정리

이번 정리는 기존 미커밋 작업과 2026-09-30 입력·상자 수정까지 포함한다. 커밋 규칙은 `GIT_BRANCH_RULE.md`의 Conventional Commits를 따른다. 작업 브랜치는 `feature/gameplay-polish-integration`이며 main에 직접 커밋하지 않는다.

## 1. 이미지·게임 배경

- 다섯 학과 수호알, 마음의 알, X알을 공용 이미지로 연결하고 학과 색상을 수호알과 맞춤.
- 학과별 배경을 등록하고 기존 소개용 썸네일을 제거.
- AI 정보 선별 상자는 분리된 몸통·뚜껑 원본을 사용. 투명 여백은 소스 좌표로 제외하며 기존 이미지도 보존.

## 2. 계정·DB·성장·랭킹

- 로그인 세션 조회·재시도·쿠키 호환 처리, 닉네임 설정과 표시, 서버 스토리 진행도 저장.
- 기본 HP 100, HP 포인트당 100 증가, 공격 기본 10에 포인트당 5% 복리, 방어 포인트당 피해 감소 2%(최대 50%).
- 사전게임은 경험치를 주지 않으며 사후 X알·보스 결과에 성장 보상을 연결.
- 스탯·컨트롤 보스의 누적/최단 클리어 랭킹과 팀·닉네임 기록. 관련 D1 스키마·마이그레이션 포함.
- 이번 커밋 정리는 원격 DB 마이그레이션의 신규 실행을 의미하지 않는다.

## 3. 스토리 월드·수호알 수집

- 캐릭터로 이동하고 NPC와 상호작용하여 학과 이야기·미니게임·후일담·수호알 획득으로 연결.
- 계정/로컬의 감상 기록을 이용한 첫 감상과 우리의 기억 재생·잠금 처리.
- 인벤토리는 뷰포트 별도 레이어, 알 목록만 스크롤, 우리의 기억은 하단 고정. 열린 동안 뒤쪽 수호알 버튼을 숨김.
- 배경과 하단 대사창, 수호알 획득 연출, 게임 방법 확인 후 시작 흐름.

## 4. 사후게임·공동 보스

- 입장 광장과 이동 중 X알이 출현하는 필드, 세 보스 문과 방 목록/생성/참가/방장 시작.
- 진행 중 전투 이어하기/나가기, 파티원 체력·전투 불능 표시, 공유 보스 상태 동기화.
- 실시간 위치 전송·재연결·퇴장 타이머의 브라우저 호출 대상 오류 수정.
- 보스별 스탯 적용과 MVP 수치·공격 판정 조정 및 관련 회귀 테스트.

## 5. 이아이 최종전

- 사전게임 수호알 수집에 연결된 최종 이야기. 부술 글자 강조, 문장 흔들림과 자간·내구도 조정.
- 학과별 공격·붕괴 패턴, 상단 생명바와 피해 연출, 다섯 차례 생명 감소 후 수호알 부활 흐름.
- 위쪽 고정 탄환, 반응형 화면과 충돌·전이·일시정지 테스트.

## 6. 학과 미니게임

- 이미지 배경과 픽셀 외곽선·단계형 명암·학과 색상으로 게임 요소 통일.
- 인데부의 인지/데사 공을 해당 수호알로 교체하고 굴러가는 거리 기반 회전 적용.
- 숫자야구 기록은 높이를 나눠 차지하지 않고 위에서부터 행 단위로 나열.
- AI 상자는 Space/버튼으로 열고 닫으며 뚜껑만 0.18초 경첩 회전. 원래 공 판정·충돌 크기는 유지.
- 사보 CLICK 버튼 포커스 중에도 Space/Enter로 즉시 판정. 키 반복과 포인터 후속 click의 중복 판정을 방지.

## 7. 공통 입력·UI

- 화면 이동·포커스 이탈·키 해제 시 입력 상태 정리, Shift/방향키 관련 상태 보정.
- 탑바·계정·설정·랭킹·결과 화면과 반응형 레이아웃 정리. 비활성 항목 hover 제거.
- 프로그래밍 방식으로 포커스되는 게임 컨테이너의 기본 테두리만 제거. 실제 버튼의 키보드 포커스 표시는 유지.
- 사용자 오류 화면에서는 내부 오류명·세부 정보를 숨기되 개발용 로그는 유지.

## 검증 및 제외 항목

- `npm run cf:full:check`: 테스트 429개, HTTP smoke 73개, 배포 산출물 smoke 86개, backend TypeScript 검사 통과.
- 새로운 상자 리소스 연결·뚜껑 회전/입력/일시정지, 사보 포커스 키보드 입력 회귀 테스트 포함.
- 실제 브라우저 시각 검증과 실제 Google 계정의 공동 접속 확인을 자동 테스트 통과와 동일시하지 않는다.
- `dist`, 의존성, 비밀 설정, 배포 응답을 내려받은 `deployed-*` 진단 파일은 커밋하지 않는다. 진단 파일은 로컬에 보존한다.
